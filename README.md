# 🤖 AI Agent — Level 1 to Level 8

A production-oriented AI Agent built progressively from a basic LLM + Calculator system into a multi-capability AI Agent with tools, memory, web search, RAG, planning, multi-agent orchestration, and a ChatGPT-style interface.

## 🚀 Project Overview

This project demonstrates the progressive development of an AI Agent from fundamental concepts to a production-oriented architecture.

The final agent can:

- 💬 Understand natural-language queries
- 🧮 Perform calculations
- 🔧 Use multiple tools
- 🌐 Search the web
- 📄 Retrieve information from PDFs using RAG
- 🧠 Handle multi-step tasks
- 🤖 Coordinate multiple agent capabilities
- ⚡ Run a local LLM using Ollama
- 🖥️ Provide a ChatGPT-style web interface
- 📝 Maintain application logs
- 🚀 Run through a FastAPI backend
